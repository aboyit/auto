Auto 3Q Studio - Windows x64 portable

Run run.bat from this folder. Python and Node.js are not required on the target PC.
BlueStacks must be installed and ADB enabled to control a game.
This package includes Android platform-tools adb.exe and its required DLLs.
The app binds only to 127.0.0.1 (ports 8000 and 5173).
Open http://127.0.0.1:5173/ if the browser does not start automatically.
Application data and logs are created under data/ in this folder.
Do not redistribute personal game data from an existing installation.
Keep the whole folder together when moving it; do not copy only run.bat.
Windows Defender/SmartScreen may prompt for an unsigned executable.
